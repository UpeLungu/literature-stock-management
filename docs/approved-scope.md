# Approved LMS Scope

The application follows the approved dashboard screenshot and contains only these modules:

- Dashboard
- Stock Count
- Reports
- Congregations
- Publications
- Users
- Settings

Administration requirements:

- Add, edit and deactivate congregations.
- Add, edit and deactivate literature categories.
- Add, edit and deactivate publications under a selected category.
- Keep the combined congregation: Long Ridge / Mapepe & Chilanga Central.
- Do not expose circuit management, ordering, transfers, barcode scanning, territory management or unrelated modules.
